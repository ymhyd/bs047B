### 五、项目介绍
项目编号：bs047B

房屋租赁小程序面向租客和管理员，支持房源查询收藏、预约看房、租赁申请与进度跟踪，并提供用户、房源、预约、租赁审核和公告等后台管理能力。

角色：租客、管理员

租客功能：注册登录、房源浏览与筛选、房源收藏、预约看房与进度查询、租赁申请与审核进度查询、个人资料维护、密码修改。

管理员功能：数据看板、用户管理、房源分类管理、房源管理、预约管理、租赁审核、公告管理、个人资料与密码维护。
